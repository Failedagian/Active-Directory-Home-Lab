 PowerShell Administration

This section documents the PowerShell commands used to administer and verify the lab environment.

 Tasks Performed

- Managed Active Directory group membership.
- Configured NTFS permissions using icacls.
- Created SMB network shares.
- Inspected SMB share permissions.
- Verified Active Directory group membership.
- Checked network configuration and connectivity.

 Commands Used

Examples of commands used during the project:

- Get-ADGroupMember
- Add-ADGroupMember
- icacls
- New-SmbShare
- Get-SmbShare
- Get-SmbShareAccess
- Resolve-DnsName
- ipconfig /all
